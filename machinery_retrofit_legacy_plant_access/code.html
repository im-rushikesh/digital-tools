Frequently Addressed Plant Concerns

security

Will this void OEM PLC warranties?

No. Our high-impedance sniffers act as passive read-only taps on external signals and diagnostic ports. We never inject active bus write cycles or reprogram OEM controller firmware unless requested.

bolt

What about heavy EMF and electrical noise?

All gateway I/O terminals feature 3,000V galvanic opto-isolation and heavy surge suppression compliant with IEC 61000-4-5 Class 4, shielding against VFD harmonics and motor switching transients.

cloud_off

Can we run entirely air-gapped without cloud?

Yes. Tools Digital hardware features self-contained web dashboards, local SQLite / Influx telemetry stores, and on-premises MQTT brokers. Absolute zero cloud reliance is natively supported.
