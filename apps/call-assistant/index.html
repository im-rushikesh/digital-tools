Zero User Data Collection & Transmission Guarantee

Call Assistant : Auto does NOT collect, harvest, store, transmit, or share ANY personal or sensitive user data. All telephony assist operations (auto-answer, call-end, and call blocking) run strictly client-side on your local device. We do not have servers, databases, or third-party brokers tracking your phone activity.

terminal 1. Operational Architecture & Utility Scope

On-Device Telephony Automation Utility

Call Assistant : Auto is designed solely as an on-device utility tool. It acts as an automated helper / add-on to streamline incoming call handling for users requiring hands-free interaction, including:

  • Auto-Answering Incoming Calls: Answering phone calls automatically after a configured time delay or when connected to Bluetooth/wired audio headsets.
  • Call Cut / Hang-Up Support: Facilitating immediate or scheduled call termination without touching the screen.
  • Call Filtering & Number Blocking: Blocking unwanted or spam incoming numbers based on rules saved strictly inside your local device storage.

key 3. Android OS Permissions & Purpose Justification

Runtime Permissions Requested Strictly for Core Features

In order to fulfill its core features on Android, the app may request specific system telephony permissions. Under Google Play requirements, we explicitly explain how each is utilized:

READ_PHONE_STATE / ANSWER_PHONE_CALLS

Used strictly to detect when an incoming call is ringing and trigger the automated answer or hang-up protocol according to user preferences.

READ_CONTACTS / CALL_SCREENING_SERVICE (Optional)

Used solely to identify whether an incoming caller exists in your allowed list or custom blacklist for blocking unwanted calls. Data never leaves memory.

delete 4. Data Retention & Account Deletion (Google Play Compliance)

Exempt from Cloud Data Deletion Obligations

Because Call Assistant : Auto does not require user accounts, passwords, or cloud data synchronization, no user data is held on remote servers.

All user configurations (such as auto-answer timer preferences and blocked numbers) are stored locally on your device via standard Android SharedPreferences / SQLite. When you uninstall the application or clear app data via Android Settings, all configurations are instantly and permanently destroyed from your handset.
